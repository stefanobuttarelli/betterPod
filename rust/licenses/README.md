# Dependency license sources

These license texts are not included in the published crate archives. They were copied without changes from the exact upstream commits recorded in the crates' `.cargo_vcs_info.json` files:

- Symphonia 0.5.5: `pdeljanov/Symphonia`, commit `6d533f26150953a882a6a111ebd13f0abf7129d5`, `LICENSE`.
- Lofty 0.25.5 and its workspace crates: `Serial-ATA/lofty-rs`, commit `59a3f5ad28f982102fdfaf8f458efd9eafb38747`, `LICENSE-APACHE` and `LICENSE-MIT`.
- Noise protocol workspace: `sopium/noise-rust`, commit `050ec78f8341849b4884d326f74e7933cb4a446c`, `LICENSE`.

`tools/dependency-notices.py` combines these with license files from the pinned Cargo packages. Native third-party and asset notices are supplied separately by the existing package.
